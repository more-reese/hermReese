## What this shows

This is a reference for what your own path might look like. The progress tracker shows the key insight from each module — the one-sentence summary the learner gave in their own words. The diagrams and traces show the artifacts the framework helps you produce. The reflections show what clicked and what didn't.

Every entry in `progress.md` is a real assessment — the learner explained each concept back in their own words and completed a practical exercise that was verified with real tool output. The git history of this directory is the longitudinal record.
