# Session examples

Real Hermes sessions, annotated with context notes. Each file is one session — the task, what Hermes did, what worked, what didn't, and what I learned.

## Naming convention

`YYYY-MM-DD_brief-description.md`

## What to include

Each session note captures:
- **The task:** What I asked Hermes to do, in plain language
- **The approach:** What skills/tools Hermes used, in what order
- **The outcome:** What actually happened — including failures
- **The lesson:** What this session taught me about agent capabilities, limitations, or product gaps
