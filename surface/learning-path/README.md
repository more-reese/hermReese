# Learning Path

How I'm learning Hermes Agent from first principles — the structured curriculum, the practice exercises, and the assessment results. This is the trace of a developing relationship with the tool, made visible.

The curriculum is maintained as a Hermes skill (`hermes-learning-path`) that loads whenever I'm doing learning work. The skill holds the procedure and the module breakdown. This directory holds the evidence — what I actually did, when, and how I scored.

## How it works

Each module follows a cycle: **learn → practice → assess → record**.

- **Learn**: Read the doc with Hermes. Plain-language explanation. Understand the *why*, not just the *what*.
- **Practice**: Do the thing for real — run the command, create the skill, schedule the job.
- **Assess**: Two checks — knowledge (explain it back in my own words) and skills (produce verifiable output).
- **Record**: Results go here. The git history is the longitudinal record.

## Structure

- **[progress.md](progress.md)** — The track: where I am, what I've completed, scores, dates, notes.

## The three tiers

| Tier | Modules | Goal | Est. Time |
|------|---------|------|-----------|
| Beginner | 1–4 | Get up and running, basic conversations, built-in tools | ~1 hour |
| Intermediate | 5–10 | Messaging, tools, skills, memory, cron | ~2–3 hours |
| Advanced | 11–14 | Architecture, adding tools, creating skills, contributing | ~4–6 hours |

Derived from the [official learning path](https://hermes-agent.nousresearch.com/docs/getting-started/learning-path).

## Why this exists

hermReese is the archetypal trace artifact for my developing relationship with Hermes Agent. The learning path is the first structured expression of that relationship — where "learning to use Hermes" becomes visible, measurable, and traceable over time.

The skill holds the curriculum. This directory holds the evidence. Memory holds the position. Together they form a loop: learn → practice → assess → record → resume.
