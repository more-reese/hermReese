# Artifacts

What my interactions with Hermes produce. Each artifact traces back to a Hermes session — the skill I built through a conversation, the project I shipped with the agent as collaborator, the writing I published through agent-assisted research.

## Contents

- **[skills/](skills/)** — Custom skills I've built for Hermes. Each one is a case study in turning a raw capability into a useful product experience.
- **[projects/](projects/)** — Shipped projects built with or through Hermes. Links to live repos with descriptions and how Hermes was involved.
- **[writing/](writing/)** — Published writing produced through Hermes sessions — articles, research reports, and the thinking that connects them.

## What this shows

These aren't demos. They're real tools, real skills, and real published work — each produced through a Hermes session, with the git history showing the agent as a collaborator. The Co-Authored-By trailers on commits reflect this: the agent is a collaborator, not a tool.

The through-line: I build with agents because thinking and making are the same act when the tool gets out of the way. Hermes is the tool that gets out of the way.
